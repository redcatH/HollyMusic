## 🎯 品质和音源图标系统

### 品质类型映射
```
FLAC 24bit (🎵) → 红色     - 最高品质
FLAC (♪)       → 紫色     - 高品质  
320K (◆)       → 蓝色     - 中品质
128K (●)       → 灰色     - 低品质
```

### 音源类型映射
```
酷我 🎵  → 蓝色
酷狗 🎼  → 黄色
QQ音乐 🎶 → 绿色
网易云 ♫ → 红色
咪咕 🎤  → 粉色
```

### 使用方式
```typescript
import { parseQuality, parseSource, getQualityInfo, getSourceInfo } from '@/lib/quality-icons'

// 解析品质
const quality = parseQuality('FLAC 24bit') // 'flac24bit'
const qualityInfo = getQualityInfo(quality)
// { icon: '🎵', label: 'FLAC 24bit', color: 'text-red-500' }

// 解析音源
const source = parseSource('网易云') // 'wy'
const sourceInfo = getSourceInfo(source)
// { icon: '♫', label: '网易云', color: 'text-red-600' }
```

## 🔍 搜索功能详解

### useSearch Hook 特性

```typescript
const { 
  query,           // 当前搜索词
  source,          // 当前选中的音源
  results,         // 搜索结果
  loading,         // 加载状态
  error,           // 错误信息
  search,          // 执行搜索函数
  setSource,       // 更改音源
  clearCache,      // 清空缓存
} = useSearch()
```

### 防抖和缓存
- **防抖时间**：300ms（用户停止输入300ms后自动搜索）
- **缓存时间**：30分钟（相同搜索词+音源自动使用缓存）
- **缓存键**：`source:keyword:page:limit`

### 搜索流程
```
用户输入 → 防抖 → 检查缓存 → 调用 /api/search → 缓存结果 → 更新 UI
```

## 📊 API 集成

### 调用的 API 端点

**搜索端点**
```
GET /api/search?source=kw&keyword=周杰伦&page=1&limit=30
```

**响应格式**
```typescript
{
  success: boolean
  data?: {
    list: Array<{
      id: string

      quality?: string
      source: string
      pic?: string

  }
  error?: {

  }
}
```

## 📝 常见问题

**Q: 搜索没有结果怎么办？**
A: 可能是网络问题或该音源没有这首歌。尝试更换音源或使用不同的关键词。

**Q: 品质/音源图标显示不正确？**
A: 确保后端返回了正确的 `quality` 和 `source` 字段。检查 `/api/search` 响应。

**Q: 缓存如何清空？**
A: 在代码中调用 `clearCache()` 方法，或刷新浏览器。
