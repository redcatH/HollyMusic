## v0.31.0-preview.1（2026-11-05）

**完整对比**：[v0.30.5 → v0.31.0-preview.1](https://github.com/redcatH/HollyMusic/compare/v0.30.5...v0.31.0-preview.1)

### 新增功能

- 音源管理新增测试歌曲设置：腾讯、网易、酷我、酷狗、咪咕各选择一首歌曲，复用于不同音源的测试；建议选择需要 VIP 且支持 FLAC 的歌曲。
- 上传脚本、添加订阅、更新订阅先生成候选，可进行快速检查或完整下载检查，查看实际编码、位深、采样率、时长及试听片段提示，并试听已下载的音频。
- 支持重测已有音源、查看最近测试和更新前后的结果、取消任务、重试失败项；由用户确认导入及默认启用的平台，也可仅保存为停用音源。
- 测试复用现有 LX VM，使用独立本地 Node 子进程，提供执行超时、内存和网络请求限制；不需要额外服务、端口、令牌或 Docker 测试环境。

### 修复与验证

- 修复音源子进程权限参数未实际传入 Node 的问题；聚合脚本的网络请求在并发上限后排队，兼容正常的多平台请求。
- 应用关于页面包含从版本元数据读取版本号的更新。
- 增加上传、订阅、候选确认、取消及网络隔离测试，并在发布镜像中检查本地测试进程、音频解析依赖和候选报告持久化。

### 升级说明

- 这是供人工验证的预发布版本，仅更新 `preview` 通道。
- 新增 `SourceTestDraft` 数据表保存候选与报告；升级前备份数据库、配置及音源目录。原有账号、收藏、歌单及音源配置保持兼容；原部署启动脚本会自动应用迁移，源码部署需先运行 `prisma migrate deploy`。
- 首次使用请在「设置 → 音源管理」为各平台选择测试歌曲。音频检查能识别编码与时长，不代表能够证明原始母带无损或保证整个 VIP 曲库可用。
- 部署及资源限制详见 [音源测试说明](../source-testing.md)。
