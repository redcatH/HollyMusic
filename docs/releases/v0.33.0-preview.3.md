### 平台插件与汽水音乐

- 管理员可以在「系统管理 → 平台插件」导入脚本。一个脚本可提供多个平台的目录功能，导入后即可启用可用功能。后台支持按功能测试、切换提供方、回滚和删除。
- 平台插件支持单曲与歌单搜索、推荐、分类、榜单和漫游。仓库提供离线 demo 供开发和验收使用，真实平台脚本由部署者自行维护。Subsonic 搜索也会读取已启用的单曲插件，播放仍通过已启用的兼容音源。

### 播放与缓存

- 播放优先选择音源声明支持的档位，服务端确认候选全部失败时停止重复降档请求。前后端控制台记录播放失败原因。
- 汽水歌曲在已知音质时显示相应标签。切换同一首歌的音质会复用已缓存的歌词，能可靠匹配的旧磁盘歌词继续可用。

### 升级

- 本版新增平台插件的 SQLite 表。官方 Docker 镜像启动时自动应用迁移。源码部署请按 [开发指南](https://github.com/redcatH/HollyMusic/blob/v0.33.0-preview.3/docs/DEVELOPMENT.md) 运行数据库迁移。
