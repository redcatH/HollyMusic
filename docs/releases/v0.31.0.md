## v0.31.0（2026-11-05）

**完整对比**：[v0.30.5 → v0.31.0](https://github.com/redcatH/HollyMusic/compare/v0.30.5...v0.31.0)

### 新增功能

- 音源列表和平台矩阵可点击名称打开共用详情窗口，集中展示当前脚本、完整订阅地址和脚本更新时间，支持复制及编辑订阅地址。
- 管理员可下载当前已安装的音源 JS 脚本，用于备份、分享及重新导入；导出保留原始字节，不重新拉取上游内容。
- 正式提供音源测试流程：各平台配置测试歌曲，上传、订阅和更新先形成候选，支持快速检测、完整检查、试听、取消、重试及更新前后对比，由用户确认导入和启用平台。
- 关于页面显示当前应用版本。

### 问题修复

- 保存订阅地址不替换当前脚本、不改变脚本更新时间；后续更新继续经过测试和确认，旧地址对应的候选不能覆盖新配置。
- 打开已有音源的测试窗口仅预校验，明确开始后才保存测试记录；未测试的上传及订阅候选可从「最近测试」的待处理区域恢复。
- 修复音源子进程权限参数和聚合脚本并发请求排队兼容问题。
- 加强试听片段及不完整音频识别，修复正式播放与离线缓存误用异常音频的问题，并支持清理、恢复受影响的缓存。

### 升级说明

- 这是正式版本，发布双架构镜像并推进 `latest` 通道。
- 从 `v0.31.0-preview.2` 升级无需新增数据库迁移。账号、收藏、歌单、音源配置和有效测试报告继续使用。
- 从 `v0.30.5` 升级新增 `SourceTestDraft` 表；Docker 启动流程自动应用迁移，源码部署需运行 `pnpm exec prisma migrate deploy`。升级前备份数据库、配置和音源目录。
- 保存新订阅地址后，点击「拉取并测试更新」获取候选并确认应用。单独下载的 JS 文件不保留订阅关系，需要持续更新时同时分享订阅链接。
- 详细操作及检测含义见 [音源测试说明](https://github.com/redcatH/HollyMusic/blob/v0.31.0/docs/source-testing.md)。
