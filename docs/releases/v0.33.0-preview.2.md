## v0.33.0-preview.2（2026-11-27）

**本次变更** [v0.33.0-preview.1 → v0.33.0-preview.2](https://github.com/redcatH/HollyMusic/compare/v0.33.0-preview.1...v0.33.0-preview.2)

**完整对比** [v0.32.0 → v0.33.0-preview.2](https://github.com/redcatH/HollyMusic/compare/v0.32.0...v0.33.0-preview.2)

### 本次修复

- 歌单、收藏、播放历史及推荐列表按批补查歌曲音质。已有记录可显示补查到的母带、空间混音和六声道版，下载弹窗也会更新可选档位。
- QQ 音乐、网易云音乐和酷狗音乐可补查歌曲详情，酷我音乐和咪咕音乐使用平台已返回的音质信息。详情暂时无法获取时，保留列表已有的档位。
- 网页播放器在旧记录缺少 Hi-Res 或母带时仍按用户偏好尝试取流。Subsonic 原格式播放在选档前补查缺少的音质信息。

### 包含的预览功能

- 桌面和移动端音质菜单支持母带与「优先环绕」，播放栏显示实际播放档位。取流失败时会先尝试能提供同一档位的其他音源，再降档。
- 下载、离线播放和服务端音频缓存按实际取流档位记录音质。Subsonic 原格式或不限码率请求默认最高使用 Hi-Res 立体声，可通过 `SUBSONIC_STEREO_MAX_QUALITY=master` 开放母带档。

从 `v0.32.0` 或 `v0.33.0-preview.1` 升级无需新增数据库迁移。
