## v0.31.0-preview.2（2026-11-05）

**完整对比**：[v0.30.5 → v0.31.0-preview.2](https://github.com/redcatH/HollyMusic/compare/v0.30.5...v0.31.0-preview.2)

### 本次修复

- 修复点击已有音源的「测试」按钮、尚未开始检测就产生空记录的问题。打开窗口仅在 VM 中预校验脚本，不保存草稿或占用候选配额；关闭后不会留下空记录。
- 点击「开始测试」或「完整检查」后才创建记录，后续重测复用该记录；开始前核对脚本摘要，脚本已变更时提示重新打开窗口。
- 「最近测试」只将已启动任务显示为测试记录。未测试的上传、订阅及订阅更新候选保留在「待处理音源」，明确标记「未测试」，可以继续处理。
- 兼容过滤上一预览版留下的空测试草稿，并在筛选后应用显示数量限制，避免空记录挤掉实际报告。增加服务、交互和发布镜像回归检查。

### 包含的预览功能

- 腾讯、网易、酷我、酷狗、咪咕各选择一首测试歌曲，复用于所有音源；建议选择需要 VIP 且支持 FLAC 的歌曲。
- 上传、订阅和更新先生成候选，支持快速检测、完整下载检查、试听、取消、重试和更新对比，由用户确认导入及启用平台。
- 检测音频实际编码、位深、采样率、时长及疑似试听片段。测试使用独立本地 Node 子进程与现有 LX VM，无需额外 Docker 测试环境、服务、端口或令牌。
- 包含音源子进程权限参数修复、聚合请求排队兼容，以及关于页面显示应用版本的更新。

### 升级说明

- 这是供人工验证的预发布版本，仅推进 `preview` 通道。从 `v0.31.0-preview.1` 升级无需新增数据库迁移，原测试歌曲、有效报告及音源配置继续使用。
- 从 `v0.30.5` 升级会新增 `SourceTestDraft` 数据表，按现有启动流程应用迁移；升级前备份数据库、配置及音源目录。
- 首次使用在「设置 → 音源管理」选择各平台测试歌曲。编码检查不等于原始母带无损认证，单首 VIP 样本也不代表整个曲库可用。
- 详细流程及资源限制见 [音源测试说明](https://github.com/redcatH/HollyMusic/blob/v0.31.0-preview.2/docs/source-testing.md)。
