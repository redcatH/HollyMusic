## v0.33.0-preview.1（2026-11-27）

**完整对比** [v0.32.0 → v0.33.0-preview.1](https://github.com/redcatH/HollyMusic/compare/v0.32.0...v0.33.0-preview.1)

### 播放与下载

- 桌面和移动端的音质菜单新增母带和「优先环绕」。环绕偏好默认关闭，开启后会优先尝试歌曲可用的六声道版或空间混音版，并在无法播放时回到立体声。播放栏显示实际播放的音质。
- QQ 音乐、酷狗、酷我、网易云音乐和咪咕音乐根据歌曲信息及已启用音源的能力提供选档。当前音源取流失败时，会先尝试能提供同一档位的其他音源，再按可用档位降级。
- 下载、离线播放和服务端音频缓存按实际取流档位记录音质，供后续播放复用。

### Subsonic

- 原格式或不限码率请求默认最高使用 Hi-Res 立体声。实例管理员可设置 `SUBSONIC_STEREO_MAX_QUALITY=master` 开放母带档。

### 升级说明

- 本版本发布到 `preview` 通道。从 `v0.32.0` 升级无需新增数据库迁移。
