截图使用当前真实前端页面和本地演示数据，不连接用户账号或第三方音源。演示曲目、歌单和歌词仅用于展示布局；封面采用不含第三方标识的马赛克示意图。平台切换标签中的品牌名称在截图前以不透明马赛克遮挡，按钮形状、选中状态和控件位置保持真实。

更新截图时：

1. 使用同一版本页面，保持上述视口与一致主题；避免加载中、报错或空白状态。
2. 检查平台名称、商标、头像、封面水印及个人账号信息，全部遮挡或使用无标识的演示内容。歌曲封面与歌词面板的背景层也需要检查。
3. 保留产品本身的文字、图标、圆角和阴影；遮挡范围以品牌或图像区域为界，不覆盖操作控件。
4. 用普通 JPEG/PNG 保存最终截图；不要仅添加可关闭的遮挡层或提交未处理的原始截图。
5. README 中桌面图单独一行，手机图等宽并排；更新图片后检查桌面和手机上的 README 排版与相对链接。
